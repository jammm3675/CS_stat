# Predictor & Analyzer for FACEIT

Это Telegram Mini App, созданное для анализа матчей на платформе FACEIT, оценки шансов на победу и выявления слабых игроков в команде противника.

## Технологический стек

- **Бэкенд:** Python (FastAPI)
- **Фронтенд:** React.js (TypeScript)
- **База данных:** Supabase (PostgreSQL)
- **API:** FACEIT Data API v4
- **Развертывание:** Render

---

## 1. Настройка и получение ключей

Перед первым запуском убедитесь, что вы выполнили все шаги из файла `GETTING_STARTED.md`:
1.  Получили ключ API от FACEIT.
2.  Создали проект и базу данных в Supabase и получили URL/ключ.
3.  Создали в корне проекта файл `.env` и заполнили его полученными ключами по примеру из `.env.example`.

---

## 2. Как запустить проект локально

Для разработки вам нужно будет запустить два процесса одновременно: сервер бэкенда и сервер фронтенда.

### Запуск бэкенда (FastAPI)

1.  Перейдите в папку `backend`:
    ```bash
    cd backend
    ```
2.  Создайте виртуальное окружение и активируйте его:
    ```bash
    python -m venv venv
    source venv/bin/activate  # Для Windows: venv\Scripts\activate
    ```
3.  Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```
4.  Запустите сервер:
    ```bash
    uvicorn main:app --reload
    ```
Сервер будет доступен по адресу `http://127.0.0.1:8000`.

### Запуск фронтенда (React)

1.  Откройте новый терминал и перейдите в папку `frontend`:
    ```bash
    cd frontend
    ```
2.  Установите зависимости:
    ```bash
    npm install
    ```
3.  Запустите сервер для разработки:
    ```bash
    npm start
    ```
Приложение откроется в браузере по адресу `http://localhost:3000`.

## 3. Как фронтенд общается с бэкендом?

Связь происходит через HTTP-запросы (API-вызовы).

-   **На фронтенде** в файле `frontend/src/api.ts` есть переменная `API_BASE_URL`. Локально она указывает на `http://127.0.0.1:8000`. Когда фронтенд делает запрос, он отправляет его на этот адрес.

-   **На бэкенде** в файле `backend/main.py` настроен `CORSMiddleware`. Эта технология позволяет серверу принимать запросы от другого домена (в нашем случае, от `localhost:3000`). Без этой настройки браузер блокировал бы такие запросы из соображений безопасности.

При развертывании мы просто изменим `API_BASE_URL` на публичный адрес нашего бэкенда на Render.

## 4. Развертывание на Render (бесплатный тариф)

### Шаг 1: Развертывание бэкенда

1.  Зайдите в свой аккаунт на [Render](https://render.com/).
2.  Нажмите **"New +"** и выберите **"Web Service"**.
3.  Подключите свой GitHub-репозиторий.
4.  Настройте сервис:
    -   **Name:** `faceit-predictor-backend` (или любое другое имя)
    -   **Root Directory:** `backend`
    -   **Environment:** `Python 3`
    -   **Build Command:** `pip install -r requirements.txt`
    -   **Start Command:** `uvicorn main:app --host 0.0.0.0 --port $PORT`
5.  Нажмите **"Advanced"**, чтобы добавить переменные окружения.
6.  Нажмите **"+ Add Environment Variable"** и добавьте все три ключа из вашего `.env` файла:
    -   `FACEIT_API_KEY`
    -   `SUPABASE_URL`
    -   `SUPABASE_KEY`
7.  Нажмите **"Create Web Service"**. Render автоматически начнет сборку и развертывание. После завершения скопируйте URL вашего бэкенд-сервиса (он будет выглядеть как `https://your-backend-name.onrender.com`).

### Шаг 2: Развертывание фронтенда

1.  Вернитесь на главную панель Render.
2.  Нажмите **"New +"** и выберите **"Static Site"**.
3.  Выберите тот же репозиторий.
4.  Настройте сайт:
    -   **Name:** `faceit-predictor-frontend`
    -   **Root Directory:** `frontend`
    -   **Build Command:** `npm install && npm run build`
    -   **Publish Directory:** `build`
5.  Нажмите **"Advanced"**, чтобы добавить переменную окружения.
6.  Нажмите **"+ Add Environment Variable"** и добавьте одну переменную:
    -   **Key:** `REACT_APP_API_URL`
    -   **Value:** Вставьте сюда URL вашего бэкенд-сервиса, который вы скопировали на предыдущем шаге.
7.  Нажмите **"Create Static Site"**.

После завершения развертывания ваш фронтенд будет доступен по публичному URL и будет отправлять запросы на ваш работающий бэкенд. Этот URL вы можете использовать для подключения к вашему Telegram-боту.
